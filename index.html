Customer support · Orders

AI-Powered Customer Support & Order Management

  • n8n
  • AI Agent
  • Google Gemini
  • Google Sheets
  • Chat memory

The problem

On a busy day, restaurant staff answer the same questions again and again: what is on the menu, what is in stock, how to order. Slow replies and mistyped orders cost sales.

What it does

A chat agent greets the customer, shows the menu with live stock from a Google Sheet, answers FAQs, asks for the customer's name and records the order in an orders sheet. It remembers the conversation, so customers can order in plain language.

In progress: connecting the same agent to WhatsApp.

Sales · Lead handling

AI Lead Qualification

  • n8n
  • Form trigger
  • AI Agent
  • Groq
  • Google Sheets
  • Gmail

The problem

Any business that takes enquiries through a web form has the same issue. Someone has to copy each lead into a sheet, read it and write back, so leads wait for hours and some are forgotten. It applies to schools, clinics, agencies, shops and offices.

What it does

A visitor fills in an enquiry form; the demo is a course enquiry form. The workflow saves the lead in Google Sheets, an AI agent reads the enquiry and writes a personalised reply, and Gmail sends it. The email carries buttons so the lead can answer “Yes, I am interested”, “Yes, I am still interested” or “I am not interested”. The AI's message is stored next to the lead in the sheet.

Operations · Inventory

Medical Store Inventory Management

  • n8n
  • AI Agent
  • Google Gemini
  • Airtable
  • Chat memory

The problem

Pharmacy staff are asked all day whether a medicine is in stock, which brand it is and whether it needs a prescription. Checking a register or a spreadsheet each time is slow.

What it does

A chat assistant that answers from the store's inventory in Airtable. Ask for the stock of a medicine, or which medicines are in a category, and it replies with the quantity, the manufacturer and whether a prescription is needed. It can also update a record.

IT operations · Monitoring

Website Downgrade and Upgrade Manager

  • n8n
  • Schedule trigger
  • HTTP request
  • If condition
  • Gmail

The problem

When a website goes down, the owner often hears about it from a customer. Every hour offline can cost sales, and nobody wants to check the site by hand.

What it does

On a schedule, the workflow sends a request to the website and checks the answer. Depending on the result, it prepares a status message and emails it through Gmail: one message when the site is up and a different one when it is not.

Email automation

Auto Email Reply System

  • n8n
  • Gmail
  • Google Gemini
  • Text Classifier

The problem

Orders and general questions land in the same inbox. When replies are slow, customers go somewhere else.

What it does

When a new email arrives, the workflow decides whether it is an order or an inquiry, asks Gemini to write a fitting reply, and saves it as a Gmail draft. A person checks the draft before sending, so nothing goes out unreviewed.

More workflows are in development. I am building new ones every week.
