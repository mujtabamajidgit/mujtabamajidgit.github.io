Featured · demo for a restaurant

AI-Powered Customer Support & Order Management

  • n8n
  • AI Agent
  • Google Gemini
  • Google Sheets
  • Chat memory

The problem

On a busy day, restaurant staff answer the same questions again and again: what is on the menu, what is in stock, how to order. Slow replies and mistyped orders cost sales.

What it does

A chat agent greets the customer, shows the menu with live stock from a Google Sheet, answers FAQs, asks for the customer's name and records the order in an orders sheet. It remembers the conversation, so customers can order in plain language.

In progress: connecting the same agent to WhatsApp.

Email automation

Auto Email Reply System

  • n8n
  • Gmail
  • Google Gemini
  • Text Classifier

The problem

Orders and general questions land in the same inbox. When replies are slow, customers go somewhere else.

What it does

When a new email arrives, the workflow decides whether it is an order or an inquiry, asks Gemini to write a fitting reply, and saves it as a Gmail draft. A person checks the draft before sending, so nothing goes out unreviewed.
