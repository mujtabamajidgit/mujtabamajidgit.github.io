AI Job Discovery & Application Assistant

A form-driven workflow that finds jobs, removes ones you already saw, scores the rest with AI and saves them to a tracker.

Built withn8n, Form trigger, HTTP Request
IntegrationsAI scoring, Google Sheets, Gmail
RoleDesign, build and testing

The problem

Job hunting means checking many sites, losing track of what you have seen and guessing which jobs fit.

The solution

A form takes the search details and the workflow validates them, fetches jobs, normalises the results and applies filters. It removes jobs already in the tracker sheet, then loops through the new ones. For each, an AI request scores the match and the output is validated. Jobs that meet the minimum score are shortlisted; others are marked below threshold or as AI error. Everything is saved to a tracker in Google Sheets, and Gmail sends a review digest and a results notification.

How it works

  1. Submit a search

    A form starts the run and the input is parsed and validated.

  2. Fetch and clean jobs

    The workflow requests jobs, normalises them, applies filters and removes duplicates.

  3. Skip known jobs

    It reads the tracker and drops jobs already saved.

  4. Score each job

    A loop sends each job to an AI model for a match score, and the output is checked.

  5. Sort and save

    Jobs are marked shortlisted, below threshold or AI error and written to the tracker.

  6. Get the digest

    Gmail sends a review digest and a results email.
