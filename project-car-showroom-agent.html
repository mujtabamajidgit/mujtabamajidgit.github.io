Car Showroom Customer Support Agent

A chat agent that answers buyer questions and can look up vehicles in a Google Sheet.

  • n8n
  • AI Agent
  • Google Gemini
  • Google Sheets
  • Chat memory

The problem

Car buyers ask about models, availability and opening hours at all hours, and a slow answer sends them to another showroom.

The solution

A chat agent that greets visitors, answers questions about the showroom and can look up the vehicle list in a Google Sheet. It remembers the conversation, so a buyer can keep asking follow-up questions. It is shaped by my background in automotive sales.

How it works

  1. A visitor writes in the chatThe message starts the workflow.
  2. The AI agent reads the messageA Google Gemini model with chat memory works out what the visitor wants.
  3. It can look up vehiclesThe agent can read rows from a Google Sheet that lists the showroom's vehicles.
  4. It repliesIt answers, or asks which make or model the visitor wants to check.

See it working

What the demo shows

  • A greeting that welcomes the visitor to the showroom.
  • A reply to “What cars do you sell?” that asks which make or model the visitor is interested in, so it can check availability.
  • A follow-up question about opening hours, answered in the same conversation.

A good fit for

  • Car showrooms and dealers
  • Motorbike and tyre shops
  • Any retailer where buyers ask about stock before visiting
